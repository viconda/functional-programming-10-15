## Содержание работ

- № 10. Персистентные структуры, pyrsistent, монады и дерево поиска с версиями.
- № 11. Реактивная библиотека и онлайн-аукцион с виртуальным временем.
- № 12. RxPY, мониторинг, asyncio и сценарии парковки.
- № 13. Модульное ядро, процессы, потоки, asyncio, Pandas и фильтры изображений.
- № 14. pytest, Hypothesis, toolz, pyrsistent, returns и планировщик расписания.
- № 15. Рефакторинг корзины магазина, тесты эквивалентности и метрики двух версий.

## Запуск

Нужен Python 3.12. Из корня репозитория:

```shell
python -m pip install -r requirements.txt
python -m lab10.main
python -m lab11.demo
python -m lab12.main
python -m unittest lab11.test_mini lab12.test_rx -v
```

Работы 13–15 запускаются из своих папок:

```shell
cd lab13
python main.py
python -m pytest --cov=analytics --cov-report=term-missing
python -m ruff check src tests
python -m mypy src/analytics
```

Для lab14 имя пакета `schedule`, для lab15 `shop`.
Полный повтор измерений работ 13–15: `python measure.py` из корня.
Время замеров зависит от компьютера и текущей нагрузки.
